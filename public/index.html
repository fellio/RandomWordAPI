Word API

634,367 語の単語リストからランダムなワードを返す API です。

Endpoints



  
Method & Path説明

  
GET/POST /wordランダムな単語を1つ返す。?count=N (1-100) で複数取得。POSTはJSONボディ可

  
GET/POST /all全単語をページネーション表示。?limit=100&offset=0 (limit 最大1000)

  
GET/POST /search?q=app検索。mode=prefix|contains|suffix、limit 指定可

  
GET/POST /words/:word単語がリストに存在するか確認

  
GET /words.txt生データ (1行1語)
